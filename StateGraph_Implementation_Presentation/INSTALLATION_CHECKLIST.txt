TROUBLESHOOTING CHECKLIST
=========================

❌ Error: "ModuleNotFoundError: No module named 'langchain'"
✓ Solution:
  1. Run: pip install -r requirements.txt
  2. Restart Jupyter
  3. Run cell again

❌ Error: "KEY not found in environment"
✓ Solution:
  1. Check .env file exists
  2. Check contents: KEY=sk-zK7xMXa2pANc64xuf4oaTA
  3. Restart Jupyter (it reads .env on startup)
  4. Run cell again

❌ Error: "Connection refused" or API timeout
✓ Solution:
  1. Check internet connection
  2. Verify BASE_URL is correct
  3. Check API key is valid
  4. Try again (might be temporary)

❌ Jupyter won't start
✓ Solution:
  1. Run: pip install --upgrade jupyter
  2. Run: jupyter --version
  3. Run: jupyter notebook again

❌ Kernel keeps crashing
✓ Solution:
  1. Close Jupyter completely
  2. Restart terminal/command prompt
  3. Run: jupyter notebook
  4. Open notebook again
